# 알림 올리는 법 (선생님용)

알림 하나는 `src/content/notices/` 폴더 안의 파일 하나입니다. GitHub 웹사이트에서 바로 만들고 고칠 수 있으며, 저장(커밋)하면 2~3분 뒤 사이트에 나타납니다.

## 새 알림 만들기

1. GitHub 저장소에서 `src/content/notices` 폴더로 들어갑니다.
2. **Add file → Create new file**을 누릅니다.
3. 파일 이름을 `날짜-짧은영어이름.md` 로 적습니다. 예: `2026-11-02-uniform.md`
   - 파일 이름이 알림 주소가 됩니다. 한글, 띄어쓰기 대신 영어와 `-`를 써 주세요.
4. 아래 틀을 붙여 넣고 고친 뒤 **Commit changes**를 누릅니다.

```markdown
---
title: 11월 2일(월)부터 동복 착용
date: 2026-10-26
grades: [1, 2, 3]
category: 가정통신문
important: false
bring: []
---

여기에 본문을 적습니다. 빈 줄로 문단을 나눕니다.

- 목록은 줄 앞에 - 를 붙입니다.
- **굵게** 쓰려면 별표 두 개로 감쌉니다.
```

## 맨 위 항목 설명

| 항목 | 뜻 | 적는 법 |
|---|---|---|
| `title` | 제목 | 그대로 적기 |
| `date` | 올린 날 | `2026-10-26` 형식 |
| `grades` | 대상 학년 | `[1, 2, 3]`, `[2]`, `[1, 3]`. 빼면 전 학년 |
| `category` | 분류 | `공지`, `가정통신문`, `행사`, `준비물` 중 하나 |
| `important` | 중요 표시 | `true`로 하면 제목 앞에 빨간 '중요'가 붙음 |
| `bring` | 준비물 | `[체육복, 물병]`. 없으면 `[]` 또는 줄을 지움 |
| `due` | 준비물이 필요한 날 | `2026-10-30`. 이 날과 전날에 첫 화면 칠판에 나옴 |
| `files` | 첨부 파일 | 아래 '첨부 파일' 참고 |

## 첨부 파일

1. PDF를 `public/files/` 폴더에 올립니다. 파일 이름은 영어로 해 주세요. 예: `2026-10-field-trip.pdf`
2. 알림 맨 위에 다음을 더합니다.

```yaml
files:
  - name: 현장체험학습 안내문 (PDF)
    path: files/2026-10-field-trip.pdf
```

PDF 안의 내용은 자동 검사가 읽지 못합니다. 학생 명단, 서명란이 채워진 동의서처럼 개인정보가 담긴 파일은 올리지 마세요.

## 학사일정 고치기

`src/data/schedule.yaml` 파일을 고칩니다. 항목 하나는 이렇게 생겼습니다.

```yaml
- title: 1학년 현장체험학습
  date: 2026-10-30
  grades: [1]
```

여러 날이면 `end: 2026-11-13`, 쉬는 날이면 `holiday: true`를 더합니다. 줄 앞의 띄어쓰기 칸 수를 위 항목과 똑같이 맞춰 주세요.

## 올리면 안 되는 것

이 사이트는 누구나 볼 수 있습니다. 다음 내용은 올리지 않습니다.

- 학생 이름, 번호(몇 학년 몇 반 몇 번), 학번
- 선생님·학부모 개인 휴대폰 번호, 개인 이메일
- 성적, 출결, 상담, 건강 정보
- 사진 속 학생 얼굴

휴대폰 번호, 주민등록번호, 학번, '몇 학년 몇 반 몇 번', 개인 이메일이 들어 있으면 사이트가 갱신되지 않습니다. GitHub의 **Actions** 탭에서 빨간 X 표시를 누르면 어느 파일 몇째 줄이 문제인지 볼 수 있습니다. 고쳐서 다시 저장하면 됩니다.

학교 공식 이메일을 공개해도 된다면 `scripts/check-privacy.mjs`의 `ALLOWED_EMAIL_DOMAINS`에 학교 도메인을 더해 주세요.
